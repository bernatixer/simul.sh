Simul runs Claude Code, Codex, OpenCode and your shell in real terminals, one keystroke apart. You keep working; it tells you when an agent is done or waiting for an answer.

The spec sheet

What Simul is, without the adjectives.

Terminals
Each session is a real Ghostty terminal running the agent's own CLI, with your login, settings and MCP servers.
Agents
Claude Code, Codex, OpenCode, or any shell. Extra launch arguments per agent in Settings.
Attention
A pixel loader and a timer while an agent works; a dot when it finishes or asks for input. Built on what agents already send: progress reports, notifications, the bell.
Resume
Reopening a session continues that session's own conversation (claude --resume <id>, codex resume <id>), not the latest one in the folder.
Limits
Claude's 5-hour and weekly usage and Codex's, asked of the CLIs themselves. Hover for the reset time.
Cards
Folder, git branch and worktree on every session. Rename with a double-click, reorder by dragging.
Keys
⌘1…⌘9 switch, ⌘N new, ⌘B sidebar, ⌘W close and archive.
Privacy
Your session list is one JSON file in ~/Library/Application Support/Simul. No account, no analytics, and Simul never reads your tokens.
Built with
Swift and SwiftUI, libghostty for the terminals. MIT licensed. macOS 14+, Apple Silicon.

Install

There's no signed download yet, so for now you build it. It takes a few minutes with Apple's Command Line Tools; no Xcode needed.

$ git clone --recursive https://github.com/bernatixer/simul.sh && cd simul.sh
# Zig 0.16.0, the exact version Ghostty needs
$ curl -fsSL https://ziglang.org/download/0.16.0/zig-aarch64-macos-0.16.0.tar.xz | tar xJ -C Vendor
$ mv Vendor/zig-aarch64-macos-0.16.0 Vendor/zig
$ scripts/build-ghostty.sh && scripts/build-app.sh && scripts/install.sh

The name comes from the chess simul: one player, many boards, a move wherever someone's waiting.
