simul n. A chess exhibition where one player walks a ring of boards and moves wherever someone's waiting.

One player, many boards.

Simul is a small Mac app for running Claude Code, Codex, OpenCode and plain shells side by side, each in a real Ghostty terminal. When an agent finishes or asks you something, its card lights up and you go make your move.

Source on GitHub Build it yourself

What's in it

1See who needs you

A light circles an agent's icon while it works. When it finishes or asks you something, its card gets a badge and you get a notification. The menu bar shows how many are waiting.

2Pick up where you left off

Each Claude and Codex session keeps its own conversation. Reopen one and you're back in that exact chat, not just the latest one in the folder.

3Folders and sleep

Keep related sessions together: ⇧⌘N starts one in the same folder, or drag a card onto another. Put a session to sleep to stop it, and click it to wake it up.

4Plan limits

See how much of your Claude and Codex plans you've used, right in the sidebar. The numbers come from the CLIs themselves.

5Real terminals

Every session is a Ghostty terminal running the agent's own CLI, with your login, settings and MCP servers. Your Ghostty config sets the fonts and colors.

6Keyboard first

⌘1–⌘9 jump to a session, ⌃⇥ goes back to the last one, ⌘N starts a new one and ⌘W closes it.

7Nothing to sign up for

No account, no analytics, no API keys. Your sessions are saved in one JSON file in ~/Library/Application Support/Simul.

Build it

There's no signed download yet, so you build it yourself. It takes a few minutes and only needs Apple's Command Line Tools, not Xcode. Runs on macOS 14 or later, on Apple Silicon.

$ git clone --recursive https://github.com/bernatixer/simul.sh && cd simul.sh
# Zig 0.16.0, the exact version Ghostty needs
$ curl -fsSL https://ziglang.org/download/0.16.0/zig-aarch64-macos-0.16.0.tar.xz | tar xJ -C Vendor
$ mv Vendor/zig-aarch64-macos-0.16.0 Vendor/zig
$ scripts/build-ghostty.sh && scripts/build-app.sh && scripts/install.sh
